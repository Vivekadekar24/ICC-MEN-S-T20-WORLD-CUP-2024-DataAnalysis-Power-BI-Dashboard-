## Project Overview

This project analyzes batting and bowling performances from the ICC Men's T20 World Cup 2024 using Microsoft Power BI. The dashboard transforms cricket delivery and player performance data into interactive visualizations to identify scoring patterns, consistent batters, effective bowlers, and phase-wise match strategies.

The report contains two interactive pages:
- **Batsman Analysis:** Run scoring, batting strike rate, batting consistency, boundary contribution, and phase-wise performance.
- **Bowler Analysis:** Wickets, bowling economy, bowling average, bowling strike rate, and dot-ball performance.

## Objectives

1. Identify power hitters and consistent batters.
2. Identify bowling-friendly conditions and effective bowlers.
3. Analyze innings phases to understand scoring opportunities.
4. Compare player performance across pitches and venues where the available data supports it.
5. Explore tactics for low-scoring matches and high-pressure situations.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query for data preparation
- DAX for measures and calculations
- Excel / CSV for structured cricket data

## Dashboard Pages

### 1. Batsman Analysis

This page evaluates batting performance using interactive visualizations.

Key analysis areas:
- Leading run scorers
- Batting strike rate and batting average
- Scoring distribution and boundary contribution
- Scoring speed compared with total runs
- Sixes and fours by batter
- Powerplay, middle-over, and death-over performance
- Comparisons between leading batters and semi-finalists

### 2. Bowler Analysis

This page evaluates bowling effectiveness and the ability to restrict scoring.

Key analysis areas:
- Leading wicket-takers
- Bowling average and economy rate
- Bowling strike rate
- Dot-ball performance
- Wickets compared with bowling strike rate
- Bowling economy and runs conceded
- Comparisons between leading bowlers and semi-finalists

## Interactive Filters

The dashboard includes slicers for:
- Team
- Batsman / Bowler
- Venue
- Match Number
- Innings Phase

These filters allow users to investigate specific teams, players, venues, matches, and stages of an innings.

## Key Questions Explored

### Batting
- Which batters combine scoring consistency with power hitting?
- What does the overall batting strike rate indicate?
- How are runs distributed between boundaries and other scoring methods?
- Which innings phases provide better scoring opportunities?
- How do leading batters compare with players from semi-finalist teams?

### Bowling
- Who are the leading wicket-takers?
- Which bowlers take wickets while restricting runs?
- Which bowlers have the lowest economy rates in the selected view?
- How does dot-ball percentage help assess bowling pressure?
- What are the limitations of a donut chart for comparing bowlers?
- What does the relationship between wickets and bowling strike rate reveal?

## Business and Tactical Value

The dashboard can support cricket performance analysis by helping users:
- Identify batters who combine scoring volume and speed.
- Compare wicket-taking ability with run control.
- Examine scoring patterns across innings phases.
- Investigate venue-specific performance when sufficient data is available.
- Develop hypotheses for batting and bowling strategies in difficult conditions.

## Validation and Limitations

This is a descriptive and exploratory analytics project. It summarizes historical tournament data and supports comparisons using the available fields.

The dashboard does **not** independently predict future match winners. Future predictions would require additional modeling, relevant contextual features, and testing on unseen matches.

Venue and pitch conclusions should be treated cautiously because historical performance alone does not establish that pitch conditions caused a particular outcome.
